# 北大法宝法律检索

通过北大法宝 MCP 服务进行专业法律检索。这是法律问题的**首选检索渠道**，优先于 WebSearch 和 RAG 知识库。

## MCP 服务信息

- **服务名**: `pkulaw-mcp-law-search`
- **类型**: streamable_http
- **端点**: `https://mcp.api-inference.modelscope.net/c1c1a0a1ee5044/mcp`

## 强制工作流程

⚠️ **法律问题必须按以下顺序检索，不可跳过：**

```
法律问题
    ↓
① 北大法宝 MCP 检索（本 Skill）
    ├── 有结果 → 使用法宝权威数据
    └── 无结果 → 继续 ②
    ↓
② RAG 知识库检索
    python3 -m rag.core search "关键词"
    ↓
③ WebSearch 补充验证
    ↓
④ 综合分析回答
```

## 使用方式

### MCP 工具调用

北大法宝 MCP 服务注册后，会提供以下工具（具体工具名以实际注册为准）：

- **法律检索**: 搜索法律法规全文
- **案例检索**: 搜索裁判文书/判例
- **法学期刊**: 搜索法学论文
- **司法解释**: 搜索司法解释

### 调用示例

当用户问"盗窃罪的量刑标准"时：

1. 调用 MCP 工具搜索：`盗窃罪 量刑`
2. 获取返回的法条内容
3. 结合 RAG 知识库验证
4. 综合回答

### 检索策略

| 查询类型 | 搜索词构造 | 示例 |
|---------|-----------|------|
| 法条查询 | 罪名/法律关系 + 关键词 | "盗窃罪 量刑标准" |
| 判例查询 | 案由 + 关键词 | "盗窃 未遂 判决" |
| 司法解释 | 解释名称/编号 | "关于盗窃刑事案件司法解释" |
| 法律全文 | 法律名称 | "中华人民共和国刑法" |

## 结果处理

### 检索结果格式化

```
📖 北大法宝检索结果

【法条】《XX法》第X条
内容：...

【相关判例】
1. (2024)XX刑初XX号 - XX法院
   要旨：...

【司法解释】
《最高人民法院关于XX的解释》第X条
内容：...
```

### 结果入库

检索到的重要法律内容，应同步添加到 RAG 知识库：

```bash
# 将检索结果保存为文件
# 然后添加到知识库
python3 -m rag.core add "/path/to/saved_file.md"
```

## 注意事项

1. **MCP 服务可能有限流**：避免短时间内大量请求
2. **结果需验证**：法宝数据权威但需确认是否为最新版本
3. **与 RAG 互补**：法宝擅长检索，RAG 擅长本地快速匹配
4. **保存重要结果**：检索到的关键法条应保存到本地知识库

## 故障处理

如果 MCP 服务不可用：
1. 检查网络连接
2. 回退到 RAG 知识库检索
3. 回退到 WebSearch
4. 记录故障到 memory/YYYY-MM-DD.md
