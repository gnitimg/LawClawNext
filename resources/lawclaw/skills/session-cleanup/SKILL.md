# 会话清理

本技能保留旧 LawClaw 的会话清理能力，但不依赖 OpenClaw、Linux home 或 WSL，也不直接运行批量删除脚本。

## 默认只读

先列出候选项、绝对路径、大小、最后修改时间、Git 状态和用途，不做移动或删除。下列内容不得作为普通垃圾处理：

- 案件原始材料、脱敏映射、正式交付和审查报告；
- DSH 会话、模型/MCP 配置、API 凭证和应用用户数据；
- Git 已跟踪文件、尚未提交的源代码、技能和脚本；
- 无法确定用途或所有者的目录。

## 可清理对象

只有在确认可再生且取得用户明确授权后，才可处理构建输出、下载缓存、测试浏览器 profile、临时 OCR 环境、已关闭进程的日志和 Python 字节码。优先使用应用提供的“清理缓存”能力；没有该能力时，先移动到同一磁盘的 LawClaw 回收目录，并生成包含原路径、恢复路径、时间和原因的清单。

## 恢复与验证

执行前确认目标位于用户明确指定的目录内，不解析不受控通配符，不跨工作区递归处理。执行后验证应用仍能启动、设置仍存在、案件和正式交付未变化。恢复时按清单逐项移回；目标已存在时停止并请求用户决定，不得覆盖。
