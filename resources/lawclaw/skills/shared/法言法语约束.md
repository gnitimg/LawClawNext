## 一、术语替换表（强制执行）

以下口语表述在文书中禁止出现，必须替换为对应的法言法语：

## 二、关键句式模板（正面引导）

以下句式为法律文书中的标准表述，生成文书时优先使用：

### 2.1 合同/借贷关系建立

```
被告XX以XX为由向原告借款人民币XX元，双方就此签订《XX合同/协议》一份。
该合同约定：（列明关键条款）。
同日，原告依约通过XX方式向被告支付了上述款项人民币XX元，被告已实际收到该笔款项。
```

### 2.2 违约事实陈述

```
上述借款期限届满后/合同到期后，被告未按约定履行XX义务。
被告于XX日向原告偿还人民币XX元，尚欠XX人民币XX元。
经原告多次催告，被告再未履行任何偿付义务。
截至起诉之日，被告尚欠原告XX人民币XX元及相应利息。
```

注意：部分还款后用"尚欠"直接陈述精确金额，不用"剩余""然而""但是"等模糊或转折词。

### 2.3 法条引用（三段论）

```
依据《XX法》第XX条之规定，[法律规定的内容概括]。
本案中，[案件事实与法律规定的对应]。
因此，被告的行为已构成XX，依法应当承担XX责任。
```

### 2.4 部分还款/清偿抵充

```
被告于XX日向原告偿还借款人民币XX元。
根据《民法典》第561条之规定，该还款先抵充利息人民币XX元，
剩余人民币XX元抵充本金。抵充后剩余本金为人民币XX元。
自XX日起至实际清偿之日止的利息，以人民币XX元为基数，按XX利率计算。
```

### 2.5 结尾段（起诉状专用）

```
综上所述，原告为维护自身合法权益，依据《中华人民共和国民事诉讼法》
第一百二十二条之规定，特向贵院提起诉讼，恳请贵院依法判如所请。
```

### 2.6 结尾段（答辩状专用）

```
综上所述，原告的诉讼请求缺乏事实和法律依据，恳请贵院在查明事实的基础上，
依法驳回原告的诉讼请求。
```

### 2.7 结尾段（上诉状专用）

```
综上所述，一审判决存在认定事实不清/适用法律错误的情形，
恳请二审法院依法查明事实，正确适用法律，支持上诉人的上诉请求，
以维护上诉人的合法权益。
```

### 2.8 时间段表述

```
自XX年XX月XX日起至XX年XX月XX日止
（注意：必须使用"起...止"完整结构，禁止仅写"自XX至XX"）
```

## 三、金额与日期格式规范

### 3.1 金额表述

- **标准格式**：人民币 + 千分位阿拉伯数字 + "元"
- 示例：`人民币100,000元`、`人民币24,000元`
- **禁止**：`10万`、`10万元`、`100000元`（无千分位）、`拾万元`（纯大写）
- **诉讼请求中的金额**：可同时注明大小写，如`人民币壹拾万元（¥100,000元）`

### 3.2 日期表述

- **标准格式**：XXXX年XX月XX日
- 示例：`2023年3月15日`
- **禁止**：`2023/3/15`、`2023.3.15`、`23年3月15日`
- **时间段**：`自2023年3月15日起至2023年9月15日止`

### 3.3 利率表述

- **约定利率**：`月利率X%`或`年利率X%`
- **法定利率**：`中国人民银行同期贷款市场报价利率（LPR）`
- **禁止**：`月息X分`、`几分利`

## 四、法条引用规范

### 4.1 引用格式

- **完整格式**：`《中华人民共和国XX法》第XX条`
- **二次引用**：`该法第XX条`（同一部法律重复引用时）
- **司法解释**：`《最高人民法院关于XX的司法解释》第XX条`

### 4.2 引用语式

- **起诉状**：`依据《XX法》第XX条之规定` + 法律内容概括 + 本案适用
- **答辩状**：`根据《XX法》第XX条之规定` + 法律内容 + 反驳论证
- **上诉状**：`一审法院错误适用了《XX法》第XX条` + `本案应当适用《XX法》第XX条`

### 4.3 引用要求

- 必须具体到**法律名称+条款号**，禁止仅写"相关规定""有关法律"
- 引用法条后必须结合案件事实说明适用理由
- 禁止凭记忆编造法条内容（必须通过WebSearch验证）

## 五、"事实与理由"段落结构指引

### 5.1 起诉状结构

```
事实与理由：

[事实陈述段]：按时间线叙述合同签订、款项交付、对方违约的客观事实
（使用过去时态，客观陈述，不使用评价性语言）

[违约事实段]：明确违约行为、违约时间、催告情况、截至起诉之日的欠款金额
（精确到金额和日期）

[法律分析段]：引用具体法条，论证合同有效→被告违约→应承担的责任
（三段论：法律规定→案件事实→法律结论）

[结论段]：综上所述，原告为维护自身合法权益，依据《民事诉讼法》第122条之规定，
特向贵院提起诉讼，恳请贵院依法判如所请。
```

### 5.2 答辩状结构

```
事实及理由如下：

[收案说明]：答辩人于XX日收到贵院送达的民事起诉状副本
[立场表明]：被告认为原告起诉状中所述XX与事实不符/被告对原告XX请求不予认可

一、[事实重构段]：从被告角度重新陈述事实，指出原告主张与事实的出入
（引用证据支持）

二、[法律反驳段]：引用具体法条，论证原告主张缺乏法律依据
（三段论：法律规定→案件真实事实→原告主张不成立）

三、[损失/免责段]（如适用）：列明被告的损失/免责事由

综上，原告的诉讼请求缺乏事实和法律依据，恳请贵院依法驳回原告的诉讼请求。
```

### 5.3 上诉状结构

```
上诉理由：

上诉人认为，一审判决存在XX错误，具体理由如下：

一、认定事实不清
（指出一审在事实认定上的错误 + 列举证据）

二、适用法律错误
（指出一审错误适用的法条 + 本案应当适用的法条 + 法理分析）

三、程序违法（如有）
（指出一审程序违法的具体情形）

综上所述，一审判决存在严重错误，恳请二审法院依法查明事实，
正确适用法律，支持上诉人的上诉请求，以维护上诉人的合法权益。
```

## 六、通用质量检查清单

每份文书输出前，必须通过以下自检：

- [ ] 术语替换表：全文无口语化表述
- [ ] 句式模板：关键段落使用了标准句式
- [ ] 金额格式：统一使用"人民币XX,XXX元"
- [ ] 日期格式：统一使用"XXXX年XX月XX日"
- [ ] 时间段：使用"自X日起至Y日止"
- [ ] 法条引用：具体到法律名称+条款号，无"相关规定"
- [ ] 法条验证：所有引用已通过WebSearch验证
- [ ] 逻辑连接词：使用了"依据""鉴于""因此""综上"等
- [ ] 主观评价：全文无情绪化/主观判断表述
- [ ] 段落结构：事实→违约/反驳→法律分析→结论
