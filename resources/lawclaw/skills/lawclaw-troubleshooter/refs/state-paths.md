# State and evidence

Use this evidence order:

1. exact failure text and current task status;
2. structured task/progress state;
3. delivery files and final report;
4. reviewer reports and stamps;
5. diagnostic reports;
6. DSH session and job events, only if needed.

Default to read-only diagnosis. Enter targeted repair only after explicit authorisation, state the editable files and verification command first, and keep rollback possible.
