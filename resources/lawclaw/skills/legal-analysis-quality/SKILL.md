# 权益份额精算

## 问题定义

份额计算类法律问题的特殊危险：**漏一步全盘错，但没有哪一步是"难的"**。

这不是知识问题——Agent知道法定继承、代位继承、夫妻共同财产等规则。问题在于缺少律师的职业推理纪律："先铺全再算"。

三类思维陷阱：

| 陷阱 | 表现 | 典型错误 |
|------|------|----------|
| **静态思维** | 只看当前登记状态，忽略历史变化 | 只算登记份额，遗漏继承/赠与来源 |
| **片段思维** | 只看单一时点，不建时间线 | 遗漏中间死亡事件导致的份额流转 |
| **锚定效应** | 被显性数字锁定，停止追问 | 看到"1/3"就直接算，不追问还有没有其他来源 |

## 概率与预判禁止

⚠️ **本Skill禁止输出任何形式的概率或预判性结论。**

- **禁止**输出任何概率数字：胜率百分比、支持率、案件结果概率等
- **禁止**对案件结果做预判性结论：如"大概率获得XX份额""胜算较高"等
- **允许**的定性表述：有利/不利/存疑/需关注/建议核查
- 本Skill专注份额精算，不对诉讼结果做任何预判

## 执行流程

**强制顺序，禁止跳阶段：**

### 第1步：建时间线（禁止任何计算）

按时间顺序列出所有关键事件：

```
[日期] → [事件] → [权益变化] → [涉及主体]
```

必须追问：
- 每项权益最初从何而来？
- 中间经历过哪些变化（死亡、赠与、分割）？
- 是否存在多人连续死亡导致的多层继承？

### 第2步：列权益来源（仍然禁止计算）

对每个相关主体，逐项核查其权益来源：

- [ ] 登记份额
- [ ] 法定继承所得
- [ ] 遗嘱/遗赠所得
- [ ] 赠与所得
- [ ] 分割协议所得
- [ ] 婚姻财产转化
- [ ] 代位继承

**关键：已去世主体的份额去向必须追溯，不能因为人不在了就跳过。**

### 第3步：确定计算规则

明确：
- 各继承事件的适用法律规范
- 继承人范围和顺序
- 是否有代位继承、转继承
- 是否有特殊规定（时效、顺序、限制）

### 第4步：计算（前三问验证后才能开始）

**计算前必答三问：**

1. **完整性**：是否还有其他权益来源没考虑？
2. **时序性**：时间线是否覆盖所有关键节点？
3. **关系性**：所有主体之间的权益关系是否清晰？

三个"是"→开始计算。任何一个"不确定"→回到对应步骤补充。

### 第5步：验证

- 所有份额加总是否等于100%（或目标总份额）？
- 计算逻辑是否可被独立复现？
- 结论是否标注了假设条件和信息局限？

## 反模式

| 信号 | 错误做法 | 正确做法 |
|------|----------|----------|
| 看到"占1/3" | 直接拿1/3算 | 追问"这1/3之外还有没有其他来源？" |
| 看到"已故" | 跳过这个人 | 追溯其份额去向 |
| 只有一次继承事件 | 只算这一次 | 检查是否有多层继承（A死→B继承后也死了→B的遗产再分配） |
| 产权登记信息 | 当作完整依据 | 登记是结果，要追问形成过程 |

## 触发场景

- "计算各继承人的份额"
- "这套房子该归谁/怎么分"
- "股权怎么分配"
- "分析各方的权益比例"
- 涉及死亡+财产的任何问题
