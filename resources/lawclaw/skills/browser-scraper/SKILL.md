# 浏览器智能爬虫

使用 OpenClaw 浏览器工具模拟人类行为，爬取有反爬保护的法律网站。

## 核心原理

与纯代码爬虫不同，本 Skill 使用 Agent 控制**真实浏览器**：
- 浏览器指纹与正常用户完全一致
- 操作节奏模拟人类（随机延迟、滚动、鼠标移动）
- 能处理 JS 渲染、SPA 页面
- 遇到验证码可截图请求用户协助

## 工作流程

### Step 1: 启动浏览器

```
检查浏览器状态 → 未启动则启动 → 导航到目标网站
```

### Step 2: 模拟人类浏览

**必须遵守的行为规则：**

| 行为 | 规则 |
|------|------|
| 页面加载后 | 等待 2-5 秒（随机） |
| 点击前 | 鼠标移到元素附近，停顿 0.5-1 秒 |
| 输入文字 | 逐字输入，每字间隔 50-150ms |
| 滚动 | 缓慢滚动，每次 200-400px |
| 翻页后 | 等待 3-5 秒 |
| 两个操作之间 | 随机间隔 1-3 秒 |

### Step 3: 提取内容

使用 `browser snapshot` 获取页面 DOM，提取目标文本。

### Step 4: 保存到知识库

将提取的文本保存为文件，然后添加到 RAG 知识库。

## 目标网站配置

### 1. 国家法律法规数据库 (flk.npc.gov.cn)

**目标**: 法律法规全文

**流程**:
1. 打开 `https://flk.npc.gov.cn`
2. 等待页面加载（Vue SPA，需要 5-8 秒）
3. 在搜索框输入法律名称（如"中华人民共和国刑法"）
4. 点击搜索按钮
5. 等待结果加载
6. 点击目标法律条目
7. 等待详情页加载
8. Snapshot 提取法律全文
9. 保存到 `rag/knowledge/flk/` 目录
10. 添加到 RAG 知识库

**注意**:
- 搜索框是 Element UI 组件，需要用 `browser act` 的 type 动作
- 搜索按钮 class 为 `.search-buttn`（注意拼写）
- 结果页是动态加载，需要等待

### 2. 中国裁判文书网 (wenshu.court.gov.cn)

**目标**: 裁判文书全文

**流程**:
1. 打开 `https://wenshu.court.gov.cn`
2. 等待页面加载
3. 如需登录 → 截图通知用户
4. 在搜索框输入关键词（案由、当事人等）
5. 点击搜索
6. 等待结果列表加载
7. 逐个点击文书条目
8. Snapshot 提取文书全文
9. 保存到 `rag/knowledge/wenshu/` 目录

**注意**:
- 可能需要登录，首次使用时请用户协助
- 有滑块验证码，需要截图请求用户处理
- 搜索结果分页，需要逐页处理

### 3. 其他可扩展网站

在 `rag/sources.json` 中添加新源，`browser` 字段设为 `true`。

## 验证码处理

当遇到验证码时：

1. 截图：`browser screenshot`
2. 通知用户：发送截图，说明遇到了验证码
3. 等待用户手动处理
4. 用户确认后继续爬取

## 速率控制

| 参数 | 值 | 说明 |
|------|-----|------|
| 页面间等待 | 3-10 秒 | 随机 |
| 每批次数量 | 5-10 页 | 然后暂停 30 秒 |
| 每日上限 | 100 页 | 避免触发风控 |
| 错误重试 | 3 次 | 每次间隔 30 秒 |

## 与 RAG 集成

爬取的内容自动添加到 RAG 知识库：

```bash
# 保存为文件
# 然后执行
在当前案件工作区中调用已配置的知识库工具导入“<文件路径>”，名称为“<名称>”。未配置知识库工具时只保存抓取结果，不得临时启动 WSL。
```

## 注意事项

1. **合法性**: 仅爬取公开可访问的内容，不绕过登录保护
2. **速率**: 严格遵守速率控制，不给目标服务器造成压力
3. **数据安全**: 爬取的数据仅存储在本地
4. **验证码**: 不自动破解，请求用户协助
5. **日志**: 记录每次爬取的详细日志到 `memory/YYYY-MM-DD.md`
