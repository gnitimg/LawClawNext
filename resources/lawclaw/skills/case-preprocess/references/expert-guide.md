# 法律案件材料信息指引

> Agent 生成材料目录时的参考知识。告诉 Agent：什么信息通常在什么文书里。

---

## 常见文书类型及核心信息

### 起诉状
| 信息类型 | 具体内容 |
|---------|---------|
| 当事人 | 原告/被告/第三人的姓名、身份证号、住址、联系方式 |
| 诉讼请求 | 具体金额、利息计算方式、行为请求（如"解除合同"） |
| 事实理由 | 案件时间线、关键事件描述 |
| 证据清单 | 提及的证据名称和编号 |
| 管辖依据 | 约定管辖或法定管辖的理由 |

### 答辩状
| 信息类型 | 具体内容 |
|---------|---------|
| 答辩意见 | 对原告诉请的逐条认可/否认 |
| 抗辩理由 | 程序抗辩（管辖、时效）、实体抗辩 |
| 反驳证据 | 被告方的证据名称 |
| 反诉请求 | 如有反诉，反诉的具体内容 |

### 判决书/裁定书
| 信息类型 | 具体内容 |
|---------|---------|
| 认定事实 | 法院确认的案件事实（最权威版本） |
| 法律适用 | 引用的法条和法律 reasoning |
| 判决结果 | 主文内容（金额、行为、费用分担） |
| 上诉信息 | 上诉期限、上诉法院 |

### 借款合同/借条/欠条
| 信息类型 | 具体内容 |
|---------|---------|
| 金额 | 本金数额（大写+小写） |
| 利率 | 约定利率、计算方式 |
| 期限 | 借款起止日期 |
| 担保 | 担保人、抵押物 |
| 签署 | 签署日期、签署人 |
| 还款 | 还款方式、还款计划 |

### 银行流水/转账记录
| 信息类型 | 具体内容 |
|---------|---------|
| 交易明细 | 每笔转账的金额、时间、双方账号 |
| 交易摘要 | 备注内容（如"还款""借款"） |
| 余额 | 各时间点的账户余额 |
| 累计 | 一段时间内的收支总额 |

### 微信/短信聊天记录
| 信息类型 | 具体内容 |
|---------|---------|
| 沟通内容 | 双方的具体对话 |
| 承认/承诺 | 对事实的承认、还款承诺 |
| 催收记录 | 催款的时间、内容、对方回应 |
| 协商过程 | 调解、和解的讨论内容 |
| 时间线 | 消息发送的时间戳 |

### 身份证明/营业执照
| 信息类型 | 具体内容 |
|---------|---------|
| 个人 | 姓名、身份证号、住址 |
| 企业 | 公司名称、统一社会信用代码、法定代表人 |

### 证据材料（通用）
| 信息类型 | 具体内容 |
|---------|---------|
| 证据名称 | 证据的标题 |
| 证明目的 | 这份证据要证明什么 |
| 证明内容 | 证据的具体内容摘要 |

## 实体类型定义（知识图谱用）

| 类型 | 颜色标识 | 提取规则 |
|------|---------|---------|
| 人物 | 蓝色 (4) | 所有自然人姓名，标注角色（原告/被告/证人/代理人/法官） |
| 组织 | 青色 (5) | 公司、银行、法院名称，标注类型 |
| 金额 | 红色 (1) | 具体数字+单位，标注上下文（本金/利息/赔偿/费用） |
| 日期 | 绿色 (6) | 关键时间节点，标注事件类型 |
| 法律关系 | 橙色 (2) | 借贷/担保/买卖/租赁/合伙等，标注依据文件 |
| 证据 | 紫色 (3) | 证据编号和名称，标注证明目的 |

## 关系类型定义（知识图谱用）

| 关系 | 方向 | 说明 | 典型来源 |
|------|------|------|---------|
| 借贷 | A → B | A借给B | 借条、合同 |
| 担保 | A → B | A为B担保 | 担保条款 |
| 转账 | A → B | A向B转账 | 银行流水 |
| 代理 | A → B | A代理B出庭 | 委托书 |
| 起诉 | A → B | A起诉B | 起诉状 |
| 签约 | A ↔ B | 双方签订合同 | 合同 |
| 催收 | A → B | A催促B还款 | 聊天记录 |
| 签署 | A → 文件 | A签署了某文件 | 合同、借条 |
| 证明 | 证据 → 事实 | 证据证明某事实 | 证据目录 |
| 包含 | 文件 → 信息 | 文件中包含某信息 | 所有文书 |

## 信息定位速查（Stage 2 核心参考）

> "要找 X 信息，去什么文件找"

| 我要找的信息 | 最可能在什么文书里 |
|-------------|-----------------|
| 原告是谁、要什么 | 起诉状 |
| 被告怎么回应 | 答辩状 |
| 借了多少钱 | 借条/借款合同 |
| 实际给了多少钱 | 银行流水/转账记录 |
| 约定多少利息 | 借条/合同（无约定视为无息） |
| 有没有催过款 | 聊天记录 |
| 对方有没有承认 | 聊天记录、通话记录 |
| 担保情况 | 合同担保条款、担保合同 |
| 管辖法院 | 合同约定、被告住所地 |
| 诉讼时效 | 最后还款/催收日期 |
| 法院怎么认定的 | 判决书 |
| 谁赢了、判了多少 | 判决书主文 |
| 上诉截止日 | 判决书送达日期 + 15天 |
| 证据原件在哪 | 证据目录 |
| 还了多少 | 银行流水、收条 |
| 双方有没有调解 | 聊天记录、调解记录 |
| 合同有没有解除 | 通知函、聊天记录 |
